# AI Agent Room Deploy

Public deployment mirror for the AI Agent Room runtime.

This repository contains only the files required to run the current Dashboard/API service on Render.

It intentionally excludes:
- secrets and credentials;
- employee or Excel data;
- portal source code;
- internal project documentation;
- development history and test assets.

Source of truth: private repository `Abdulaev64/ai-agent-room`.

Do not add secrets to this repository.
